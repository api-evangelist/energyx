# EnergyX

> Energy Exploration Technologies, Inc. (EnergyX) is a critical-materials technology company founded in 2018 by Teague Egan, headquartered in Austin, Texas, with operations in Texarkana, Antofagasta (Chile) and San Juan (Puerto Rico). It develops direct lithium extraction (DLE) technology under the GET-Lit platform, SoLiS lithium-metal battery technology, and NUKE-it membranes for lithium isotope separation and nuclear fuel-cycle applications, and produces lithium hydroxide, lithium carbonate and lithium dihydrogen phosphate.

EnergyX publishes no developer program, no API documentation, no SDKs, no CLI, no MCP server and no developer portal. It is a materials and process-technology company, not a software vendor.

The one machine-readable interface it exposes is the WordPress REST content API behind energyx.com. It is anonymously readable, read-only, unmetered, requires no signup, and is not advertised anywhere on the site — it was found by probing, not by documentation. API Evangelist derived fifteen OpenAPI 3.1 documents covering 59 operations from the server's own HTTP OPTIONS schema documents on 2026-08-12. There is no provider-published specification; there is no provider claim of any kind about this surface.

- Base URL: https://energyx.com/wp-json
- Authentication: none for reads. Writes require a WordPress application password with no public issuance path.
- Rate limits: none published, none signalled. `per_page` is capped at 100.
- Errors: WordPress envelope `{code, message, data:{status}}`, not RFC 9457. Match on `code`.
- Versioning: `wp/v2` path namespace, inherited from WordPress core. No versioning or deprecation policy.
- Change tracking: no ETag, no Last-Modified, no Cache-Control. Use the `modified_after` query parameter.
